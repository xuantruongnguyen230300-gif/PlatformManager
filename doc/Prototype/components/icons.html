Component — Icons

Sidebar hiện tại (dashboard.html/danh-muc-dti.html) dùng SVG outline vẽ tay, đặt tên placeholder theo spec/sidebar-menu/ui-spec.md §1.3 — file đó tự ghi "quyết định hoãn" vì chưa chốt thư viện icon.

Đã CHỐT (2026-08-15): icon library = PrimeIcons — đi kèm quyết định dùng PrimeNG làm component library chính (xem doc/huong_dan/wiki-core/fe/04-design-token-system.md). Khi build Angular thật, thay toàn bộ SVG placeholder dưới đây bằng đúng class PrimeIcons ở cột 3 — chỉ 5 khoá cần map lại, rủi ro đổi thấp đúng như spec gốc đã lường trước.

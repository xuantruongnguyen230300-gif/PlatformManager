**Two real WCAG failures were found and fixed while re-extracting**: `warn` on `warn-bg` measured 3.88:1 and `bad` on `bad-bg-hover` 3.89:1, both under AA 4.5:1 (badge text is 10px, so it does not qualify for the relaxed 3:1 large-text threshold). `--warn` and `--bad` were darkened; lint warnings dropped 8 → 6, with the two remaining being linter false positives comparing a colour against its own alpha tint.

⚠️ **`platform-manager-preset.ts` re-declares 10 of these colours as TS constants for the PrimeNG ramps.** Any future value or name change must land in **both** files or the CSS and the component library will render different colours with nothing failing.
